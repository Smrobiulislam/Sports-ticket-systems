# GitHub Deployment

This repository contains:
- `frontend/` — Vite/React frontend
- `backend/` — Node.js backend
- `docs/` — project documentation

Important:
- GitHub Pages can host the built frontend, but it cannot run the Node.js backend.
- The backend must be deployed separately on a Node.js-compatible hosting service.
- Configure frontend API/base URLs to point to the deployed backend before production use.
