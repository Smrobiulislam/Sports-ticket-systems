# Flat GitHub Upload

All project files are intentionally placed at repository root so they can be uploaded without folders.

Important:
- This is an upload-friendly flat copy of the project.
- The original Vite/React import paths may require adjustment if you want the frontend to run from this flattened layout.
- For reliable production builds, the original `frontend/` and `backend/` folder structure is recommended.
- GitHub Pages cannot run the Node.js backend; deploy the backend separately.
